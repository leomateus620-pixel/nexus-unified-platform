# Fonte autoral

`3tentos-reconstruction.blend` foi produzido com Blender 4.5.10 LTS pelo script `scripts/blender/generate_unit.py`. As onze imagens utilizadas estão empacotadas no arquivo; não depende do caminho absoluto da máquina de autoria.

As coleções separam terreno, silos próximos/distantes, equipamentos, edifícios, cercas, protótipos vegetais e blockout. A cena inclui instâncias da vegetação ancorada e câmeras A–D. O cadastro central e a calibração estimada permanecem em `src/industrial/data/site.json`; regenere os ativos depois de alterar parâmetros.

Os volumes são editáveis. Espessuras estimadas não são especificações de fabricação. Não há interiores, dados CAD de campo ou validação dimensional.
