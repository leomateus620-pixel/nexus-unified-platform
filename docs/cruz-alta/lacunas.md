# Lacunas de verificação por estrutura

Posições horizontais e perímetros provêm da interpretação de imagem e, nos conjuntos, do desenho das relações entre as peças. A coluna de altura informa a faixa de topo **representada** no modelo em relação ao piso cênico. Os valores são estimativas visuais, inclusive quando o desenho informa uma cota estimada. Uma diferença entre os extremos pode representar componentes distintos. Os setores sem checagem independente local conservam a incerteza global do registro.
